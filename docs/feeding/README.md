# 狗狗的喂养与营养

## 基础营养需求

### 六大营养素
- 蛋白质：肌肉生长和修复的基础
- 碳水化合物：能量来源
- 脂肪：提供必需脂肪酸
- 维生素：维持正常代谢
- 矿物质：骨骼发展和体液平衡
- 水分：维持生命活动的基础

### 不同阶段的营养需求
- 幼犬期（0-1岁）：高蛋白、高能量
- 成犬期（1-7岁）：均衡营养
- 老年期（7岁以上）：低脂高纤维

## 喂食指南

### 喂食时间
- 幼犬：每天3-4次
- 成犬：每天2次
- 定时定量，保持规律

### 食量参考
- 小型犬：体重的3-5%
- 中型犬：体重的2.5-3.5%
- 大型犬：体重的2-3%

### 喂食注意事项
- 避免人类食物调味料
- 不要喂食生肉
- 保持食物新鲜
- 定期清洗食具
- 避免运动后立即喂食

## 狗粮选择

### 狗粮类型
- 干粮：方便储存，牙齿清洁
- 湿粮：适口性好，水分充足
- 冻干：营养保留好，价格较高

### 选购要点
- 查看配料表
- 注意保质期
- 选择适合年龄段
- 关注品牌口碑
- 适应犬种大小

### 转换狗粮注意事项
- 循序渐进，7-10天过渡
- 观察狗狗接受程度
- 注意粪便状况

## 零食选择

### 适合的零食
- 专业狗零食
- 新鲜水果（适量）
- 蔬菜
- 鸡胸肉干
- 鱼干

### 禁止食用
- 巧克力
- 葡萄/葡萄干
- 洋葱/大蒜
- 咖啡因
- 含糖食品
- 坚果类

## 特殊情况喂养

### 怀孕母犬
- 增加营养摄入
- 多次少量
- 补充钙质

### 生病期间
- 遵医嘱调整
- 清淡易消化
- 适当加水
